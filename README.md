# 🚀 Space Mission Dashboard

This is a space mission dashboard built using React and TypeScript. The project is focused on creating a simple interface for viewing missions, satellites, and basic mission information.

## Features

- View space missions
- Browse satellite information
- 3D view of Earth and satellites
- Basic telemetry information
- Ground station status
- Space-themed dashboard interface

## Tech Used

- React
- TypeScript
- Vite
- Three.js
- React Three Fiber
- React Router
- CSS

## How to Run

1. Install the required packages:

```bash
npm install
```

2. Start the project:

```bash
npm run dev
```

3. Open the local URL shown in the terminal.
