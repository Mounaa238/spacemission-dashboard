# Space Mission Dashboard

An interactive dashboard for exploring 
- space missions
- satellites
- Earth observation 
- weather
- astronomy data

## Features

- Mission information
- Satellite information
- Earth observation
- Weather and ocean data
- Astronomy and asteroid data

## Technologies

 - Frontend:
         React + TypeScript + Vite\Three.js + React Three Fiber
 - For 3d object:
         GLB / glTF
 - Styling:
         Tailwind CSS + shadcn/ui
 - Data:
         JSON / TypeScript initially → Supabase + PostgreSQL later
 - Backend:
         Supabase
 - Authentication:
         Supabase Auth
